# Lokks — Virtual Manicure Studio

واجهة تجريبية عربية RTL مبنية باستخدام React + TypeScript + Vite + Tailwind CSS.

## التشغيل
```bash
npm install
npm run dev
```
افتح الرابط المحلي الذي يعرضه Vite.

## البناء للنشر
```bash
npm run build
```
ملفات النشر النهائية ستكون داخل `dist/`.

## ما يتضمنه المشروع
- واجهة RTL عربية متجاوبة وهوية Lokks الوردية والعنابية.
- استوديو Canvas متحرك يتغير مع التمرير، مع رسم اليد والأظافر وإعادة تلوينها.
- 14 درجة، أوضاع الطلاء، أشكال وأطوال ولمسات نهائية.
- خيارات لون البشرة والإضاءة والسطوع.
- متجر وفلاتر منتجات وسلة وإطلالات محفوظة عبر localStorage.

## ملاحظات مهمة
- مشهد اليد الحالي مرسوم برمجياً على Canvas كنسخة أولية تفاعلية، وليس صورة فوتوغرافية حقيقية. للحصول على محاكاة واقعية دقيقة لكل ظفر، أضيفي صور يد أمامية/مغلقة عالية الدقة مع أقنعة (masks) ومواقع أظافر معايرة لكل وضعية داخل `public/` ثم استبدلي طبقة رسم اليد في `HandCanvas`.
- الأسعار تجريبية بالريال السعودي، ولا توجد بوابة دفع أو مخزون أو قاعدة بيانات مرتبطة. زر متابعة التسوق حالياً يوضح ذلك.
- لا توجد صور منتجات خارجية؛ قوارير الطلاء مرسومة بـ CSS لتظل خفيفة وقابلة للتخصيص.
